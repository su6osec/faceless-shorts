# GEMINI.md - Google Antigravity & Gemini Workspace Instructions

This workspace contains the `faceless-shorts` framework created by su6osec.

When prompted to generate a short-form video:
1. Review user topic and choose or generate a 4-7 scene script with high retention (3-second hook, open loops).
2. Use `.agents/skills/faceless-shorts/SKILL.md` for guidance.
3. Use the Python CLI `python -m faceless_shorts generate` to produce publication-ready 1080x1920 MP4 videos.
4. Output YouTube title, description, and hashtags from the generated metadata file.
