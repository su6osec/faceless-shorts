# 100% Free Resources & API Catalog

Every tool and resource included in this project operates with **zero cost, zero subscriptions, and no credit card required**.

---

## 1. Free AI Visual Generation

### Pollinations.ai (Integrated by default)
* **Website**: https://pollinations.ai
* **API Endpoint**: `https://image.pollinations.ai/prompt/{prompt}?width=1080&height=1920&model=flux&nologo=true`
* **Features**: Flux.1, SDXL, Turbo models. Completely keyless, unlimited free requests via standard GET URLs.

### Hugging Face Serverless Inference API (Alternative)
* **Website**: https://huggingface.co
* **Models**: `black-forest-labs/FLUX.1-schnell`, `stabilityai/stable-diffusion-xl-base-1.0`
* **Free Tier**: Free user API token with generous rate limits.

---

## 2. Free Text-to-Speech (TTS)

### Microsoft Edge-TTS (Integrated by default)
* **Library**: `edge-tts` (Python)
* **Features**: Over 300 natural human voices in 100+ languages. Zero cost, no API key, word-boundary timestamp streaming.

### Kokoro-82M (Local Open-Source Alternative)
* **GitHub**: https://github.com/hexgrad/kokoro
* **Features**: 82M parameter lightweight TTS model under Apache license. Runs ultra-fast locally on CPU or GPU with incredible naturalness.

### Piper TTS (Local Offline)
* **GitHub**: https://github.com/rhasspy/piper
* **Features**: Ultra-fast local neural TTS running on Raspberry Pi and low-end hardware.

## 3. Free Stock Video Footages

### Pexels API
* **Website**: https://www.pexels.com/api/
* **Cost**: 100% Free (Free API key gives 200 requests/hour, 20,000 requests/month).
* **Content**: Thousands of vertical 1080x1920 4K/HD royalty-free clips.

### Pixabay API
* **Website**: https://pixabay.com/api/docs/
* **Cost**: 100% Free.
* **Content**: Vertical videos, illustrations, and sound effects.

### Wikimedia Commons & Public Domain Archive
* **Website**: https://commons.wikimedia.org / https://archive.org
* **Content**: Historical photos, government space missions (NASA public domain), ancient art scans.

## 4. Copyright-Free Music & Audio

### Procedural Synthesizer (Built-in)
* **Engine**: Pure Python + FFmpeg
* **Features**: Synthesizes 50Hz sub-bass drones, binaural beats, and ambient soundscapes offline. Immune to YouTube Content ID.

### Free Music Archive (FMA) & Incompetech
* **Website**: https://freemusicarchive.org / https://incompetech.com
* **License**: Creative Commons Attribution (CC-BY) / CC0.

### YouTube Audio Library
* **Website**: https://studio.youtube.com (Audio Library tab)
* **Features**: Thousands of tracks pre-cleared for YouTube monetization.
